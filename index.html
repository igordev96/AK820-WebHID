AJAZZ AK820 Pro — WebHID key remapper

Remap the top and Fn layers, and assign media keys, from the browser. No install, no admin rights — just WebHID (Usage Page 0xFF13, VID 0x0C45).

Before you click: close the AJAZZ desktop app — only one program can hold the config interface. Use Chrome, Edge or Opera on desktop (WebHID is unavailable in Firefox, Safari and on mobile).
Unofficial community tool. Not affiliated with AJAZZ. It writes the key table to your keyboard; use it at your own risk and keep the vendor app as the recovery path.

3 · Deep probe — is the reply real?

Runs four experiments back to back: baseline stability, an echo test with a distinctive payload, command isolation, and a 32-read stream test. Together they tell us whether the 64-byte reply is generated by the device or is just our own buffer handed back.

4 · Raw command

Bytes here are the application payload; the browser adds the leading 00 report ID. So 04 18 goes on the wire as 00 04 18 00 …. Up to 64 bytes is sent as one frame; longer payloads are split into bare 64-byte chunks, exactly like the vendor app (its 576-byte keymap is 9 chunks after a 04 11 … 09 announce).
Presets: 04 18 init handshake · 04 19 generic read · 04 F5 firmware version · 04 02 commit · 04 F0 end

6 · Key editor

Click a key, then choose what it should send. Edits stay in the page until you press Upload changes — the firmware has no single-key command, so the whole 576-byte layer is re-sent each time. Restore factory map puts every key back in one click. The Fn layer tab edits what each key does while Fn is held; it is a separate table, and there the keyboard's own default is spelled a zero slot, so only the keys you change are written. The keyboard cannot report either layer back, so this browser remembers the Fn overrides it wrote.

Keyboard usages are 0x00–0xE7 plus the vendor Fn at 0xAF (0xE2 is Left Alt). Media/consumer functions are in the Media group and are written with record type 0x03; in the raw box they need a c: prefix — e.g. c:0xE2 Mute — because 0xE2 alone is Left Alt.

Advanced — raw map text, packet preview

One line per key: key_index usage name. Keyboard records are encoded as 02 <modifier> <usage> 00 (modifiers become 02 <bit> 00 00); media records are 03 <lo> <hi> 00 and their usage carries a c: prefix (c:0xE2 Mute, c:0x0224 Browser back). Everything is written at offset key_index × 4; every other slot stays zero; bytes 574–575 carry the AA 55 trailer. The text mirrors the editor state — edit it, then Load from text. On the Fn layer a usage of 0x00 means no override: nothing is written to that slot.

The device mailbox keeps the previous reply until it has processed the new command, so a read issued immediately after a write returns stale data. Every reply echoes its command in byte 1, so the driver polls until the reply belongs to the command it just sent — the step tables show the status and round-trip time for each frame.
